# Smart Garden Irrigation Simulation

This example simulates a smart garden management system, specifically focusing on automated irrigation. It generates simulated sensor data for soil moisture and air temperature, then applies a simple logic to decide whether to water, preventing both under- and over-watering based on environmental conditions.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal using `python main.py`.
